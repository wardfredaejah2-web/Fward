# Tech Connect Student Club Website Plan
By Fredaejah Ward
CIS 207 – Introduction to Web Development

## Working Section 1: Website Planning

### Purpose and audience
The website introduces Tech Connect and encourages students to get involved. The audience includes students who enjoy technology and beginners who want to learn. The wording should be friendly and easy to understand.

## Content and navigation
Every main page uses the same navigation: Home, Activities, Resources, and Join Us.

- Home (studentclub.html): club name, mission, membership benefits, activity preview, and links to member resources.
- Activities (activities.html): workshops, coding challenges, speakers, hackathons, and hardware activities. Dates remain unannounced until confirmed.
- Resources (resources.html): outside learning resources and a practice routine.
- Join Us (join.html): ordered joining steps, contact status, and expandable questions.
- index.html: forwards the repository’s homepage to studentclub.html.

## Working Section 2: Wireframes
Open wireframes.html to view the desktop and phone layout plans. The wireframes show the header, navigation, main content, and footer before visual styling.

## Working Section 3: HTML Structure
Each main page uses a doctype, language attribute, head, body, page title, character encoding, and viewport meta tag. Header, nav, main, section, article, and footer elements organize the content. The home page includes h1, h2, h3, paragraphs, an hr, and unordered lists. The joining and resources pages include ordered lists. The home and resources pages have at least two external links.

## Working Section 4: CSS Design
One external file, styles.css, provides the shared design. The site uses Arial with Helvetica and sans-serif fallbacks. Dark blue headings and a pale blue background create a simple technology theme. Flexible columns, margins, padding, and readable line spacing organize the pages.

Color choices:
- Navy: #173B63
- Blue: #245E95
- Light blue: #E6F0FA
- Body text: #24364B
- White: #FFFFFF

CSS examples include element, class, attribute, and pseudo-class selectors. Hover and focus styles help users identify links. The ::marker rule colors list markers. The ::after rule adds an external-resource label.

## Working Section 5: Responsive Design
The viewport meta tag allows the layout to fit mobile screens. A media query at 760px stacks columns and moves navigation beneath the club name. Font sizing uses clamp(), and the main container has a flexible width.

## Continued development
The same files can be expanded for the final project. Add confirmed meeting details, official contact information, a working membership form, and approved club images. Do not collect personal information until an appropriate form and storage process exist.

## Assignment Scope
This plan addresses the planning, wireframing, HTML, CSS, and responsive-design topics in the supplied overview. The five working sections above organize the listed tasks. They do not claim to reproduce a separate numbered phase rubric.
