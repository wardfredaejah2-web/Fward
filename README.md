# Tech Connect Student Club Midterm
Fredaejah Ward — CIS 207

This project expands the supplied studentclub.html into four linked pages. It fixes the missing header closing tag and extra closing ul tag, adds member resources, and uses shared external CSS.

## Files
- studentclub.html: required club homepage
- activities.html: planned activities
- resources.html: technology learning links
- join.html: joining steps and expandable questions
- styles.css: shared styles and mobile layout
- index.html: optional homepage redirect
- wireframes.html: visual layout plans
- PROJECT_PLAN.md: website planning document

## IDE requirement
Open the project folder in Visual Studio Code or another instructor-approved IDE. Review and edit the files there before uploading. These prepared files alone do not establish that the assignment’s IDE requirement has been completed.

## Upload to the existing repository
Repository: https://github.com/wardfredaejah2-web/Fward
1. Extract the ZIP. Upload the files INSIDE the folder, not the ZIP itself.
2. In Fward, replace studentclub.html with this updated version and add the other files to the repository root.
3. Before uploading index.html, check whether Fward already has a homepage. Keep the existing index.html if it contains work you need. You can still publish studentclub.html directly.
4. Commit with a message such as: Update Tech Connect midterm website.
5. Open repository Settings, then Pages. Select Deploy from a branch, main, and /(root), then Save. If Pages is already configured correctly, keep the existing configuration.
6. Use the published URL shown in GitHub Pages settings. The expected club-page URL is https://wardfredaejah2-web.github.io/Fward/studentclub.html, but it must be published and verified before submitting.
7. Check the page on your phone. Submit the working GitHub Pages URL in Canvas, rather than the GitHub code-file URL.

GitHub setup reference: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
